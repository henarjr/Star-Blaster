# Star Blaster 🚀

**Star Blaster** is a 2D arcade space-shooter built with Unity. Take control of your spaceship, fight off waves of enemies, dodge incoming threats, and push your score as high as possible!

Think you can survive the chaos of space? Let's find out. 👀

## 🎮 Gameplay

Your mission is to survive as long as possible, defeat enemies, and earn the highest score you can. The longer you last, the more challenging things get!

## 🕹️ How to Play

| Input | Action |
|---|---|
| `A` / `D` | Move left / right |
| `W` / `S` | Move up / down |
| `Left Mouse Button` | Shoot |

## ✨ Features

- 2D arcade space-shooter gameplay.
- Enemy waves that challenge your survival.
- Spaceship movement and shooting mechanics.
- Scrolling space background.
- Health and score UI.
- Multiple enemy types.
- Character selection to choose your spaceship.
- Game over screen.

## 🛠️ My Additions & Improvements

This project started as a learning experience while following a Unity game development course. Along the way, I added my own features and improvements to expand the gameplay and make the experience more engaging.

- **Character Selection:** Added a selection screen that lets players choose their spaceship before starting the game.
- **Random Wave Generation:** Implemented randomized enemy waves to make each run less predictable.
- **Enemy Variety:** Added different enemy types throughout the waves to create more varied gameplay encounters.
- **High Score System:** Worked on saving and displaying the player's best score.
- **Game Flow:** Added a start menu and a dedicated game over screen.

Working on these features helped me practice Unity scripting, gameplay systems, UI, and scene management while building on what I learned from the course.
